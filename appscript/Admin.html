Panduan Format Excel
1
Siapkan file Excel (.xlsx atau .xls)
Buat sheet pertama dengan header pada baris pertama: teks_soal, kode_riasec, jenjang, opsi_a, opsi_b, nilai_a, nilai_b
2
Kode RIASEC yang berlaku: R, I, A, S, E, C, G
R=Realistik  |  I=Investigatif  |  A=Artistik  |  S=Sosial  |  E=Enterprising  |  C=Konvensional
3
Kolom Jenjang: SD, TK, atau SEMUA
SEMUA = soal tampil untuk semua jenjang. SD = khusus SD. TK = khusus TK.
Contoh Isi Excel
teks_soalkode_riasecjenjangopsi_aopsi_bnilai_anilai_b
Saya suka bermain bolaRSEMUAYa, sukaTidak suka10
Saya senang menggambarASDYa, suka sekaliBiasa saja10
